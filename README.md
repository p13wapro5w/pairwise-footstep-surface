# pairwise-footstep-surface

角色在金属、草地、木板上脚步声一样、跑跳切换没声、多人脚步重叠炸耳：脚步材质按地形标签；步频按移动速度线性；落地检测用固定高度；跑跳共用事件；多人脚步不分组；脚步延迟随帧率；室内外混响不切换；脚步和动画事件不同步；音量按距离不衰减；水下脚步仍走地面材质。audio/footstep_surface.py 是核心，tests/test_footstep_surface.py 15个红。要修的是：材质映射；速度步频；落地阈值；跑跳事件；多人分组；固定延迟；室内外切换；动画事件对齐；距离衰减；水下材质。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：音视频处理；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
